## Default Permission

Todo lo del plugin, para la pagina que viene en el APK

#### This default permission set includes the following:

- `allow-open-server`
- `allow-leave-server`
- `allow-handoff`
- `allow-set-fullscreen`
- `allow-set-playing`
- `allow-set-bars`
- `allow-minimize`
- `allow-request-network`
- `allow-device`
- `allow-update-state`
- `allow-update-check`
- `allow-update-install`
